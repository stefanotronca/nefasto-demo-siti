# Report

Ogni volta che Stefano scrive "report", viene generato un file qui con la data del giorno (`YYYY-MM-DD.md`), contenente l'aggiornamento reale di ciascun agente del team: cosa ha fatto, a cosa sta lavorando, cosa propone.

I file restano in ordine cronologico per nome (formato data ISO), sia nel repository che in locale su `~/Progetti/vetrina/reports/`.
